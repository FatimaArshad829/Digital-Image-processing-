# LAB TASK 04 — Geometric Transformations

## Files
- `2024-SET-2024-SE-24-LAB04.ipynb` — completed Jupyter Notebook.
- `input_image.png` — generated sample RGB image used by the notebook.
- `outputs/` — transformed images and interpolation comparison results.

## Run
1. Extract this folder.
2. Open Anaconda Navigator or Jupyter Notebook.
3. Open this folder and launch `2024-SET-2024-SE-24-LAB04.ipynb`.
4. Restart the kernel and select **Run All**.
5. If using your own image, replace `input_image.png` and keep the same filename, or edit `IMAGE_PATH`.

## Dependencies
Python, NumPy, OpenCV (`opencv-python`), Matplotlib, Pillow, and Jupyter.
